# NEXUS — Minisite

Minisite for the NEXUS master's thesis defense.  
Live at: **https://zarfet.github.io/nexus-minisite** (or your deployment URL)

## What it is

A single-page site that presents the NEXUS framework — a structured, evidence-based method for choosing an interface type (screen, voice, AI, spatial, automation) before the first mockup is drawn.

Built for the defense of the master's thesis *"Beyond Intuition: A Designer's Framework for Interface Type Selection"* — Master in Advanced Studies in Design, UPC / UB, Barcelona, 2026.
